# Note importanti:
- **Non cancellare il codice altrui** (il codice in questione si vede assieme)
- Per garantire **consistenza** e **uniformità** usare variabili e _nomi inglesi_ (i commenti si possono tenere in italiano)
- **Non** eseguire commit che presentano errori o con codice non funzionante
- Eseguire sempre un pull prima di un eventuale commit/push, altrimenti viene sovrascritto codice nuovo con codice vecchio o non aggiornato
